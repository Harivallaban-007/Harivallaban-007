## 🎯 About

We often know *what* we want to say — but not always *how* to say it right.

**MindVoice AI** listens to what you're about to say and helps you say it better — catching the tone, emotion, and intent behind your words before you hit send or speak up. Powered by **Groq's blazing-fast inference** and **Llama 3.3 70B**, it gives you real-time feedback so you can communicate with clarity instead of regret.

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- A [Groq API key](https://console.groq.com)

### Installation

```bash
# Clone the repository
git clone https://github.com/Harivallaban-007/MindVoice-AI.git
cd MindVoice-AI

# Install dependencies
pip install -r requirements.txt

# Add your Groq API key to a .env file
echo "GROQ_API_KEY=your_key_here" > .env

# Run the app
streamlit run app.py
```

<br>

## 📖 Usage

1. Launch the app with `streamlit run app.py`
2. Type or speak what you want to say
3. MindVoice AI analyzes tone, emotion, and intent in real time
4. Get instant feedback before you speak better and regret less
